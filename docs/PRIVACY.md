# DeepSeek Export Plus隐私说明

更新日期：2026-10-24。适用范围：DeepSeek Export Plus浏览器扩展，2.3.0及其同意控制、Word与PNG功能。维护者：[xiaohei07](https://github.com/xiaohei07)。本项目与DeepSeek官方无隶属关系。

## 读取哪些内容

首次使用会打开独立的数据与隐私页。未同意前，扩展不读取或暂存对话；可拒绝，并在需要时重新开启。扩展用于将当前DeepSeek网页对话保存到本机。同意后，用户打开导出窗口时，扩展读取当前会话的标题、网址、消息正文、轮次、附件名称及可取得的下载地址；勾选思考后，还会提取可取得的思考文字、工具记录和来源链接。对话本身可能含个人信息，导出文件会保留用户选择的原始内容。

为补全chat中的历史和折叠内容，2.3.0只有取得同意后才注册历史观察脚本；随后在DeepSeek页面载入时观察网页自然收到的历史消息响应，在页面内存中暂存当前会话的必要字段。这一步可能发生在打开导出窗口之前。它不读取Cookie、认证令牌、请求头、请求正文或浏览器的全局浏览历史，也不额外重放登录请求。思考选项控制是否写入导出文件，并不意味着网页原本收到的响应一定不含思考。

## 如何使用与传输

内容提取、文档转换、DOCX生成、PNG排版与ZIP打包在浏览器本地完成。Word公式所需图片和PNG使用包内的脚本、公式样式与字体生成，不调用第三方转换服务。维护者没有用于接收对话的后端服务，不加入广告、统计或遥测，不出售对话，也不将其用于模型训练。

分享页导出会请求DeepSeek的分享内容接口；保存图片和附件会请求DeepSeek文件服务。用户选择保存正文中的远程图片时，也可能向该图片原地址发起请求。以上下载使用不携带认证凭据的请求；对应服务仍可收到网络连接所需的IP地址等信息，服务本身的数据处理受其各自政策约束。导出过程不执行远程脚本。

导出的HTML不自动加载远程图片、脚本或字体；没有保存到本地的图片显示为链接。主动点击文档中的来源或附件链接后，浏览器会访问对应网站。MD、TXT和JSON也可能包含原始链接，打开MD时是否联网加载图片取决于阅读软件的设置。

## 保存位置与期限

| 内容 | 保存方式与清理 |
| --- | --- |
| 当前会话历史片段 | 页面内存，最多500条消息、约8MB字符串；页面刷新后重建，切换会话后不用于新会话，重新生成等请求会清理旧缓存 |
| 导出窗口中的对话与附件字节 | 浏览器内存，完成处理或关闭窗口后等待浏览器回收；关闭窗口会停止后续处理，已发出的下载请求可能仍在结束中 |
| PDF预览 | `chrome.storage.session`临时保存正文、标题和所选附件的名称、地址、大小等元数据，用于预览及按原名下载；关闭对应预览页时删除。下一次打开预览时清理超过30分钟的数据，接近容量限制时也会清理较早记录；不是严格的定时删除 |
| 同意状态 | `chrome.storage.local`保存是否同意及说明版本、更新时间；撤回后标记为未同意，不保存对话内容 |
| 格式偏好 | 2.2起在`chrome.storage.local`保存格式名称，不保存对话、思考选项或账号信息；修改格式会覆盖，卸载扩展会清除 |
| 导出文件 | 由浏览器保存到用户指定的本机目录；保留多久、是否同步或分享，由用户决定，卸载扩展不会删除已下载文件 |
| 剪贴板 | 仅点击“复制Markdown”后写入，之后由系统及用户使用的软件管理 |

附件地址可能带临时签名。长期保存建议将文件一起打包；分享导出文档之前，请自行检查其中的对话、链接和附件是否适合公开。

## 权限与选择

扩展仅在`chat.deepseek.com`注入内容脚本；`scripting`用于读取当前消息附近的必要字段，`files.deepseeksvc.com`访问权限用于下载附件，`clipboardWrite`用于复制，`storage`用于上述临时预览和格式偏好。不申请读取所有网站、Cookie、浏览历史或监控全局下载的权限。

用户可以取消思考或附件选项、只导出部分轮次、关闭导出窗口，或在浏览器扩展管理页停用、卸载插件。2.3.0还可从扩展选项或导出窗口打开“数据与隐私”，撤回后立即关闭导出窗口、停止历史观察、清空内存缓存与session临时预览、取消正在进行的附件请求。已经下载的文件和系统剪贴板不自动删除。从旧版本升级后需要刷新已打开的DeepSeek页面，移除旧版本脚本；同意后建议刷新，以便捕获完整历史。上传的图片可能只能取得DeepSeek网页预览版，导出界面与文件清单会说明。
