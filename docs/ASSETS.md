# 图像说明

小肥鱼图标用于插件图标、页面入口和导出窗口。维护者提供了本地角色参考图，并同意用于绘制。本项目用内置imagegen工具生成了新插画，再缩放为浏览器需要的16、32、48、128和256像素PNG；新绘制的图仍沿用了参考角色的特征。

2026-10-24，维护者确认已查询现有图标可以使用，要求继续保留。本版据此沿用现有图标，没有重新绘制。该确认由维护者提供，仓库不另行声称已独立核验具体角色许可；MIT代码许可与角色形象的权利范围分别处理。

参考图用于蓝发、头饰、侧鳍和服装等角色特征，没有把参考图上的文字或整张表情包放进发行包。生成图保存在`docs/images/mascot-source.png`，实际使用的尺寸位于`public/icons/`。它不是DeepSeek官方商标；代码的MIT授权不代表对既有角色形象另行主张排他权利。
