## 本轮发现的差异

用户提供的两个旧导出都是6轮对话。chat样例没有有效的导出工具段，share样例则包含相应调用；两者均有28处由旧版本额外添加的引用斜体段落。

新版本不再添加斜体，思考与工具放在同一引用块。chat补充普通搜索类型和当前页面历史响应缓存，同时保留消息快照与DOM回退。隔离浏览器中，chat的工具记录和链接同时进入MD与PDF。

## 体积变化

比较对象是本机上一版1.2.0构建，不是未经修改的上游原版，也不是运行速度基准。

| 指标 | 本机1.2.0 | Plus 2.0.0 |
| --- | ---: | ---: |
| 后台脚本 | 439,265字节 | 约7.3KiB |
| 安装包 | 1,290,992字节 | 588,045字节 |
| 解压后的安装目录 | 2,175,921字节 | 936,297字节 |

变化主要来自移除旧截图PDF依赖、删除重复扫描流程、按入口打包和只携带Chrome所需的WOFF2字体。没有做“导出速度提升几倍”的计时结论。

## 未验证与后续验收

本轮工具没有可连接的用户登录浏览器，因此**不将模拟chat及公开数据回放称为用户当前登录页面实测**。真实账号的灰度界面、尚未遇到的工具片段、特殊附件，以及超长对话仍需继续反馈。Edge、其他操作系统和其他Chromium发行版尚未分别人工验收。

建议安装后在同一对话的chat/share页面各导出一次，重点核对：实际标题、工具顺序和来源、思考是否完整、选择轮次是否符合预期、图片是否正确标注预览版、PPTX/MD/HTML附件能否打开。缺失内容应提供可公开的最小复现，不能通过增补推测文字来“补齐”导出。
